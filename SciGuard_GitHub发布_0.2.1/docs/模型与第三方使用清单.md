## 数据集来源与引用

固定实验通过 scikit-learn 1.7.2 的 `load_breast_cancer` 加载 UCI Wisconsin Diagnostic 数据集副本，共 569 个样本、30 个数值特征。训练/测试划分和预测来自本包固定脚本，不修改原始数据来源。

原始来源：[UCI 数据集页面](https://archive.ics.uci.edu/dataset/17/breast%2Bcancer%2Bwisconsin%2Bdiagnostic)。该页面标注 CC BY 4.0 许可，使用时保留归属和引用。

数据集引用：Wolberg, W., Mangasarian, O., Street, N., & Street, W. (1993). *Breast Cancer Wisconsin (Diagnostic)* [Dataset]. UCI Machine Learning Repository. [DOI: 10.24432/C5DW2B](https://doi.org/10.24432/C5DW2B)。

本作品使用其数值特征做流程演示，不把固定分类指标作为临床有效性证据。数据加载器的本地描述也保存于 scikit-learn 的 dataset.DESCR，可供复核。
