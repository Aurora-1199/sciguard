# 测试样例：正常、边界、失败

检查器及固定演示为 SciGuard 0.2.1。以下输入片段用于文本检查，不是完整可执行 Python。实际输入、预期行为和已有验证层分别列出；不会把未执行样例称为网页实测。

## 正常样例

```python
X_train, X_test, y_train, y_test = train_test_split(X, y)
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)
```

检查器预期：NO_PATTERN_FOUND，review_required=false，findings=[]。该结果只表示没有匹配 SG001。已有证据：check.test.mjs 的正确流程测试；原生 AGH trace 的 sciguard_check 调用 seq=58，结果 seq=62。

固定 corrected 实验另有真实 AGH 调用 seq=113、结果 seq=119：COMPLETED / executed=true，实际指标见 trace。固定模板包含必要导入和数据加载，不直接执行上述片段。

## 边界样例

| 输入 | 预期 | 已有验证与边界 |
|---|---|---|
| 32768 个 x 字符 | 长度检查接受，NO_PATTERN_FOUND；这不是有效 Python 的保证 | 发布副本补充核对只调用文本检查器，不执行 Python |
| 32769 个 x 字符 | 检查器抛 TypeError；run_code hook 返回 allow=false | check.test.mjs；补充核对 |
| example = "unfinished | 检查器标记 review_required=true；hook 拒绝 | check.test.mjs；补充核对；不会假装分析完整 |
| 注释中的 scaler.fit(X)，下一行 train_test_split(X) | 注释被屏蔽，不触发 SG001 | check.test.mjs 的注释／字符串测试 |

字符长度的接受不代表 Python 语法有效，当前检查器不解析完整语法。

## 失败与拒绝样例

```python
X_scaled = scaler.fit_transform(X)
X_train, X_test, y_train, y_test = train_test_split(X_scaled, y)
```

预期：POTENTIAL_RISK、SG001、fit_line=1、split_line=2；run_code hook 拒绝。在固定 risky 完整模板中，对应 fit_line=10、split_line=11。真实 AGH 固定演示调用 seq=94、结果 seq=100 为 BLOCKED / executed=false。宿主显示 Failed 表示本次风险执行被拒绝，不删除该失败标记。

| 失败输入或条件 | 预期 | 验证方式 |
|---|---|---|
| 空字符串、纯空白、非字符串 code、缺少 args | 检查器异常或 hook allow=false，reason 非空且不超过 1024 字符 | check.test.mjs；直接 hook 函数测试，不是网页记录 |
| corrected 的模拟执行端返回 code=1、timedOut=true | EXECUTION_FAILED，保留 timed_out=true | check.test.mjs 的模拟 exec；不是实际制造 Python 超时 |
| 已取消的 signal | 抛出取消异常，保留失败 | check.test.mjs，不是网页审批结果 |
| CH-07 跨函数风险 | 当前 checker 未识别，保留 missed | 原挑战集 results.json；这是已知检测失败，不应标为安全通过 |

## 如何复核

从提交包 source 目录或公开源码仓库根运行：

```powershell
node --test .\examples\packages\sciguard\check.test.mjs
node .\examples\packages\sciguard\benchmark\run-benchmark.mjs
node .\examples\packages\sciguard\benchmark\challenge\run-challenge.mjs
node .\examples\packages\sciguard\benchmark\challenge-v2\run-challenge-v2.mjs
```

这些命令不执行被检查的 Python、不调用模型 API。固定真实 Python 实验另按复现说明准备依赖。补充核对输出保存到verification/官网补充样例核对.json，明确标注仅文本检查和模拟 hook。

原生 AGH trace 及其 seq 引用用于赛事提交包核查，不随公开仓库分发；公开仓库的本地复现命令和模拟测试可独立运行。
